3. FUNCTIONAL NODE TYPES

Implement at least these seven functional node types:

START
Begins workflow execution.

DATA SOURCE
Generates or accepts structured JSON records.

FILTER
Filters records based on user-configurable conditions.

TRANSFORM
Maps, renames, calculates, or modifies record fields.

CONDITION
Routes records through True and False output connections.

DELAY
Introduces a configurable execution delay.

OUTPUT
Displays the processed results as an interactive table and JSON viewer.

Each node must have working configuration controls.

Every node must perform real operations. Decorative or nonfunctional nodes are unacceptable.
